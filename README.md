# Tirex — Online Banking & Personal Finance Dashboard

A full-stack personal finance and online banking dashboard built on the MERN stack (MongoDB, Express, React, Node.js).

## Features

- Role-based auth (Customer, Financial Advisor, Administrator) with JWT + bcrypt
- Multi-account management (checking, savings, credit, investment)
- Transaction tracking: income, expense, transfer, investment
- Category-wise budgeting with overspend alerts
- Dashboard: balance, income, expenses, savings rate, net worth
- Investment tracker: stocks, mutual funds, FDs, crypto, gold
- Reports with PDF/Excel export
- Notifications: budget limits, bills due, salary received, investment maturity, unusual spending
- Dark mode

## Stack

- Frontend: React (Vite), React Router, Recharts, Axios
- Backend: Node.js, Express, MongoDB (Mongoose)
- Auth: JWT + bcrypt
